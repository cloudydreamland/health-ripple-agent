# 智慧云脑 · 健康事件涟漪守护智能体

> 当新诊断、新处方、异常指标发生时，智能体主动推演这个事件会在患者生活里激起哪些连锁影响——而不是等用户来问。

2026 年 iCAN 大学生创新创业大赛 · AI 无代码智能体挑战赛（DuMate 智能体应用创新赛题 · 医疗健康场景）

## 这个作品解决什么问题

市面上的医疗 AI 产品都在回答"诊断准不准、随访做没做"。我们关注的是诊后那段没人管的空白：病人拿着新诊断和新处方走出诊室之后，药物和酒冲突了怎么办、复查窗口错过了怎么办、家人该注意什么、什么时候提醒才来得及。现有产品把这些问题拆给了几十条系统通知，我们把它当成一个可以推演、可以计算、可以留证的整体。

## 它是怎么做到的

**涟漪强度指数（RII）** —— 每个连锁影响按五环模型（用药安全圈 → 家庭影响圈）计算 `强度 = 100 × 严重度 × 紧迫度 × 可干预度 × e^(−0.22×(环数−1))`。每个数字都带着评分依据，医生可以逐项复算，不是黑箱给个分数。

**医疗时间学引擎** —— 窗口期、生理节律、复查周期、季节流行四类可计算的触达时机。每条触达都挂着 Timing Card：指南依据、错过代价、证据等级。为什么要现在提醒，卡片上写得清清楚楚。

**反事实护栏** —— 每次决策都记录"如果选了别的方案会怎样"，护栏逐条审计，高危路径锁定禁止下发。AI 说错话不可怕，可怕的是没有闸门。

**印鉴链存证** —— 每条决策进 SHA-256 哈希链，篡改任何一条从该处起全部校验失败，可一键导出 HL7 FHIR R4 Provenance。责任的最后一环是证据。

**五 Agent 学科会诊** —— 分诊、处方、病历、随访、涟漪守护五个智能体以专科身份辩论收敛，输出会诊纪要。现有的 AI-MDT 都还在组织真人开会，这里是智能体自己开。

## 仓库结构

```
dumate-skills/                 5 个 DuMate Skill（Agent Skills 开放标准）
  health-ripple/                 健康事件涟漪守护（核心创新）
  medical-triage/ prescription-safety/ medical-record-draft/ followup-plan/
backend/                       13 个 Spring Boot 3 微服务（20 容器一键部署）
  ripple-service/                涟漪推演 / 时间学引擎 / 反事实护栏 / 证据链
frontend/
  ripple-console/                涟漪守护指挥中心（水墨涟漪大屏）
  patient-web/ doctor-web/ admin-web/
evaluation/ripplebench/        RippleBench 量化评测（60 病例 + 自动报告）
scripts/e2e_test.py            22 步端到端测试（完整患者旅程）
sql/ postman/ deploy/
```

## 跑起来

```bash
docker compose -f deploy/docker-compose.yml up -d   # 全栈 20 容器

# 医生指挥大屏：http://localhost:5176
# 患者健康涟漪页：http://localhost:5173/ripple

py -3 scripts/e2e_test.py                           # 端到端 22 步
py -3 evaluation/ripplebench/run_eval.py            # RippleBench 量化评测
```

后端不通时大屏会自动切到内置的真实响应快照，演示现场断网也不慌。

## 测试情况

- 端到端测试 22 步全过（注册 → 分诊 → 挂号 → 病历 → 处方 → 随访 → 涟漪推演 → 回执消解 → 健康气象）
- RippleBench 量化评测 60 病例：分诊 top-1 20/20，涟漪覆盖 20/20，护栏灵敏度/特异度 100%，消解闭环 10/10
- 后端单元测试与 Skill 安全冒烟测试全过
- 值得一提的是评测过程本身：第一轮评测揪出三个真缺陷（卒中急症掉进兜底、哮喘被误路由到心内科、证据 ID 并发冲突），修复后重测才全绿——这套评测不是摆设

## 一个演示场景

医生输入："患者新诊断 2 型糖尿病，已开二甲双胍，推演健康事件涟漪。"

智能体推演出五维涟漪：禁酒、造影剂检查前停药 48 小时、两周肝肾功复查、视力模糊要立即看眼科、家属注意夜间低血糖节律……生成 16 条反事实路径，护栏锁定其中 9 条高危；事件级 RII = 74.3（红色高强度），扩散半径 5/5 环。全程证据入链，可导出 FHIR。这一整套推演在指挥中心大屏上是一幅会动的水墨涟漪。

---

安全边界：智能体会拦风险处方、会推涟漪、会掐触达时机，但不开方、不下诊断、不改治疗方案——终审权在医生。
