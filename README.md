# 智慧云脑 · 健康事件涟漪守护智能体

> 当新诊断、新处方、异常指标发生时，智能体主动推演这个事件会在患者生活里激起哪些连锁影响——而不是等用户来问。

2026 年 iCAN 大学生创新创业大赛 · AI 无代码智能体挑战赛（DuMate 智能体应用创新赛题 · 医疗健康场景）

## 这个作品解决什么问题

市面上的医疗 AI 产品都在回答"诊断准不准、随访做没做"。我们关注的是诊后那段没人管的空白：病人拿着新诊断和新处方走出诊室之后，药物和酒冲突了怎么办、复查窗口错过了怎么办、家人该注意什么、什么时候提醒才来得及。现有产品把这些问题拆给了几十条系统通知，我们把它当成一个可以推演、可以计算、可以留证的整体。

## 它是怎么做到的

**涟漪强度指数（RII）** —— 每个连锁影响按五环模型（用药安全圈 → 家庭影响圈）计算 `强度 = 100 × 严重度 × 紧迫度 × 可干预度 × e^(−0.22×(环数−1))`。每个数字都带着评分依据，医生可以逐项复算，不是黑箱给个分数。

**医疗时间学引擎** —— 窗口期、生理节律、复查周期、季节流行四类可计算的触达时机。每条触达都挂着 Timing Card：指南依据、错过代价、证据等级。为什么要现在提醒，卡片上写得清清楚楚。

**反事实护栏** —— 每次决策都记录"如果选了别的方案会怎样"，护栏用独立关键词通道+源等级通道双通道审计，高危路径锁定禁止下发，还能覆写生成器的误标。AI 说错话不可怕，可怕的是没有闸门。

**印鉴链存证** —— 每条决策进 SHA-256 哈希链（并发安全，4 线程并发回归测试锁死），篡改任何一条从该处起全部校验失败；可一键导出 HL7 FHIR R4 Provenance（哈希链证明走 FHIR 官方扩展机制，算法标识用 NIST 官方 OID）。责任的最后一环是证据。

**五 Agent 学科会诊** —— 分诊、处方、病历、随访、涟漪守护五个智能体以专科身份发言，分歧显式暴露、按"患者安全优先"规则收敛裁决，输出会诊纪要。现有的 AI-MDT 都还在组织真人开会，这里是智能体自己开。

**72 小时涟漪预报** —— RII 回答"现在有多大浪"，预报回答"浪什么时候来"：把守护触达的强度按时间学语义在 72 小时轴上确定性叠加，医生看到"今晚 0-3 点有低血糖峰"，患者端翻译成"未来三天守护天气趋势"。每缓解一项触达，对应峰值就从曲线里消失。

**今日守护队列** —— 基层医生早上打开大屏的第一个答案："今天该先管谁"。跨患者按"升级就医 > 未缓解 > 今日到期 > 气象指数"排序，每行带理由。

**守护价值账本** —— 从印鉴链聚合系统真实做过的守护：审计决策数、高危路径锁定数、黄金窗口触达数、回执缓解数。计数型账本，不虚构概率——"避免了 X 次死亡"那种话需要真实世界对照数据才配说。

## 跑起来

```bash
docker compose -f deploy/docker-compose.yml up -d   # 全栈 21 常驻容器

# 医生指挥大屏：http://localhost:5176
# 患者健康涟漪页：http://localhost:5173/ripple

py -3 scripts/e2e_test.py                           # 端到端 27 步
py -3 evaluation/ripplebench/run_eval.py            # RippleBench v3 量化评测
py -3 scripts/verify_all.py                         # 一键复现全部验证（提交前必跑）
```

两端视觉：医生大屏为「夜航墨」暗色水墨（深暖墨底 / 玻璃拟态面板 / 发光水墨图表 / 朱砂印点睛），患者端为「数字宣纸」晨纸浅色（同一设计系统的适读表达），一墨两纸、昼夜同源。评委如何亲手操作两端见 [评委交互指导书](评委交互指导书.md)。

后端不通时大屏会自动切到内置的真实响应快照，顶栏徽章同步变为 SNAPSHOT 并标注快照捕获时间——演示现场断网不慌，屏幕上是什么数据也从不撒谎。

## 第七/八/九轮：从"可信"到"可治理、可落地、可开放"

- **人机共驾终审**：智能体提出的每条守护计划，医生在指挥大屏上一键**通过 / 改期 / 否决**——否决立即从预报、天气、队列消失，审定理由随**印鉴链存证**（GUARD_PLAN_REVIEW 决策类型，患者越权审定 403 有 e2e 回归）；审定记录（谁/何时/以什么理由）从印鉴链读出，可视化展示在时辰守护盘旁。"终审权在医生"从此不是口号，是每一个按钮 + 一本可读的账。
- **依从性沙盘**：预报面板拖动"守护执行度"滑杆，同一引擎确定性重算非季节驱动贡献 ×(1−执行度) 的沙盘曲线——预演"守护被执行后浪有多高"，逐桶可复算。
- **一键守护报告**：大屏生成可打印的诊后守护摘要（RII 总览/Top 风险/审定后的守护计划/循证依据/印鉴链哈希），打印随病历交给患者——基层落地最后一公里。
- **对话式回执 + 语音输入**：患者端用自己的话说情况（"好多了 / 还是没好转 / 已经去医院"），本地确定性关键词解析为三态回执，解析不了就明说——不联网、不臆造；症状分诊与文字回执支持**语音说**（Web Speech API，zh-CN），不支持的环境自动隐藏优雅降级；适老模式同步放大。
- **家属守护圈**：一键生成 **HMAC 签名的只读分享链接**（7 天有效），家属免登录看到守护态势 + 家属须知 + 72h 趋势 + 消解率。**最小披露设计**：不含姓名、诊断、决策记录——知情权与隐私权的边界显式划清（e2e 有 PHI 泄漏断言 + 篡改令牌拒绝断言）。
- **社区涟漪雷达**：个体的涟漪汇成社区的潮汐——跨患者聚合近 7 天守护信号（未缓解/升级就医），潮汐指数 + TOP 信号榜回答"辖区现在正在流行什么守护问题"。个体守护 → 群体预警的自然延伸。
- **MCP Server**：涟漪推演/气象/预报/队列/雷达/验印暴露为 **MCP 标准工具**（[mcp/](mcp/README.md)，附 6 项冒烟测试）——任何第三方 AI 助手都能在对话中直接调用守护能力，从产品升级为协议。
- **RII 开放规范**：[docs/RII-SPEC.md](docs/RII-SPEC.md) 把涟漪强度指数的公式、等级语义、λ=0.22 与阈值 45/25 的推导依据、可复算性要求整理成可被任何系统引用实现的开放规范。
- **负载基准**：[scripts/bench_load.py](scripts/bench_load.py) 公开测什么怎么测，本机单节点实测数字见 [docs/PERF-BENCHMARK.md](docs/PERF-BENCHMARK.md)。
- **视觉：墨玉鎏金**（motionsites 获奖模板组件语言融合：Bio-Age 暗金健康数据 × Systema 纯黑克制 × F1 数字分级）：漆器近黑底 + 鎏金洞察色（FIG 编号/潮汐/角标）+ 朱砂只留给印章与风险；**真字体本地化打包**（Noto Serif SC + JetBrains Mono，离线可用），编辑部级排版；守护实况 ticker 直播感。

## 测试情况

- 端到端测试 27/27 全过（注册 → 分诊 → 挂号 → 病历 → 处方 → 随访 → 涟漪推演 → 回执消解 → 健康气象 → 通知双通道 → **越权/未鉴权/患者越权审定安全负例** → **医生审定守护计划闭环（否决剔预报+沙盘+印鉴链）** → **家属守护圈（HMAC令牌+免登录只读+PHI泄漏断言+篡改拒绝）+ 社区涟漪雷达（医生可读/患者403）**）
- RippleBench v3：**60 开发病例 + 10 盲测病例（held-out，开发期未参与调参）+ 12 项判定**——分诊 top-1 20/20，涟漪覆盖 20/20，护栏灵敏度/特异度 100%（真特异度与防幻觉分口径均 100%），**盲测集 10/10**，消解闭环 10/10，**第六轮创新系统级检查 5/5**（预报确定性/诚实空态/队列降序/角色守卫/价值账本）
- 后端单元测试全绿：ripple-service 37 项（含**哈希链 4 线程并发回归**、护栏误标覆写、**预报节律峰/缓解清零**、**审定/沙盘/家属圈令牌/社区雷达**）、ai-service 29 项（含安全网红线覆写）
- Skill 安全冒烟 5/5
- 评测过程本身就是卖点：四轮评测累计揪出 8 处真缺陷（卒中急症掉进兜底、哮喘误路由心内、证据 ID 并发冲突、哈希链并发分叉、否定语境误判、儿科被成人规则抢跑、涟漪守护通知从未真正落库、灵敏度口径脱钩），修复后复测全绿——盲测集首轮就抓到了开发集两轮迭代都没暴露的问题，这套评测不是摆设

## 一个演示场景

医生输入："患者新诊断 2 型糖尿病，已开二甲双胍，推演健康事件涟漪。"

智能体推演出五维涟漪：禁酒、造影剂检查前停药 48 小时、两周肝肾功复查、视力模糊要立即看眼科、家属注意夜间低血糖节律……生成 18 条反事实路径（含"如果患者不遵禁酒"的患者行为风险路径），护栏锁定其中 11 条高危；事件级 RII = 74.3（红色高强度），扩散半径 5/5 环。全程证据入链，可导出 FHIR。这一整套推演在指挥中心大屏上是一幅会动的水墨涟漪。
