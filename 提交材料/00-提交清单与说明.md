## 一b、90 秒自动演示模式（录屏专用）

打开 `http://localhost:5176/?demo=1`：系统自动完成落石推演→护理路径→护栏晶格→发起会诊→医生终审→印鉴验印→依从性沙盘→社区雷达→回首屏，右下角"自动演示中"徽章提示进度。**录屏 B 段开着 OBS 录这一页即可**；A 段（DuMate 平台操作）仍需人工按 `04-演示录屏剧本.md` 录制。

## 二、代码仓库

- **地址**：https://github.com/cloudydreamland/health-ripple-agent
- **内容**：13 个 Spring Boot 3 微服务 + 双端前端（医生指挥大屏 / 患者门户）+ 5 个 DuMate Skill + MCP Server + RippleBench 评测体系 + 全部验证脚本
- **CI**：GitHub Actions 四岗（后端单测 / 双端构建 / MCP 协议自检 / 安全自审），每次推送自动验证，当前全绿

## 三、一键复现（评委可亲自执行）

```bash
# 1. 全栈部署（21 常驻容器，全部带健康检查）
docker compose -f deploy/docker-compose.yml up -d

# 2. 打开双端
#    医生指挥大屏：http://localhost:5176   （免登录，LIVE 徽章）
#    患者健康门户：http://localhost:5173   （种子账号 13800000001 / 123456）

# 3. 一键复现全部验证（四步全绿）
py -3 scripts/verify_all.py

# 4. 更多可复跑脚本
py -3 scripts/bench_load.py            # 负载基准
py -3 scripts/drill_offline.py         # 断网演练（击穿+降级+自愈）
py -3 scripts/security_self_audit.py   # 安全自审
node mcp/smoke-test.mjs                # MCP 冒烟
```
