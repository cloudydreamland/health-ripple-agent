# 代码仓库与复现指南

## 仓库

**https://github.com/cloudydreamland/health-ripple-agent**

- CI 徽章：每次推送自动执行四岗验证（后端单测 / 双端生产构建 / MCP 协议自检 / 安全自审）
- 技术栈：13 个 Spring Boot 3 微服务（KingbaseES 信创兼容 / Redis / RabbitMQ）+ Vue 3 双端 + 5 个 DuMate Skill（Agent Skills 开放标准）+ MCP Server + RippleBench v3 评测体系

## 目录层级（仓库根）

```
dumate-skills/        5 个 DuMate Skill（health-ripple 为核心，9 个动作）
backend/              13 个微服务（ripple-service 是核心：推演/RII/预报/审定/家属圈/雷达）
frontend/apps/        ripple-console 医生指挥大屏（夜航墨）· patient-web 患者门户（数字宣纸）
mcp/                  MCP 标准工具服务器 + 冒烟测试（6 工具）
evaluation/           RippleBench v3（60 开发病例 + 10 盲测病例 + 系统级检查）
scripts/              e2e 27 步 / verify_all 一键复现 / 负载基准 / 断网演练 / 安全自审
deploy/               docker-compose（21 容器全健康检查）+ Nacos 配置 + Dify 工作流
docs/                 System Card / RII 开放规范 / 验证报告 / 截图资产
提交材料/             本文件夹（比赛提交物）
```

## 从零到运行（评委复现路径）

```bash
git clone https://github.com/cloudydreamland/health-ripple-agent
cd health-ripple-agent
docker compose -f deploy/docker-compose.yml up -d
# 等待 2 分钟（健康检查），然后：
#   医生指挥大屏  http://localhost:5176
#   患者健康门户  http://localhost:5173   （13800000001 / 123456）
py -3 scripts/verify_all.py     # 一键复现全部验证（四步全绿）
```

## 关键自动化脚本（全部可复跑）

| 脚本 | 用途 |
|---|---|
| `scripts/verify_all.py` | 后端单测 + e2e 27 步 + RippleBench + Skill 冒烟 一键全绿 |
| `scripts/e2e_test.py` | 27 步端到端（全旅程 + 3 类安全负例 + 审定闭环 + 家属圈断言） |
| `scripts/bench_load.py` | 负载基准（p50/p95/p99/RPS，含 72h 预报与印鉴链验印） |
| `scripts/drill_offline.py` | 断网演练（击穿核心服务 → 降级诚实 → 恢复自愈） |
| `scripts/security_self_audit.py` | 安全自审（硬编码凭据扫描，CI 同源） |
| `mcp/smoke-test.mjs` | MCP 协议冒烟（握手/工具清单/实调） |
