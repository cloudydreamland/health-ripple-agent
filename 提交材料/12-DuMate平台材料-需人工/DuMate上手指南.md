# DuMate 平台从零上手指南（本作品专用）

> 目标：把本作品的 5 个 Skill 装进 DuMate、建出智能体、跑通演示、拿到提交所需的链接与截图。
> 前置：技能包已打好在 `skills-zip/` 目录（5 个 zip，每个内含 `SKILL.md` + `scripts/main.py`，纯 Python 标准库、无第三方依赖）。

---

## 第 0 步 · 装客户端（5 分钟）

1. 打开官网 **https://www.dumate.cn/** 下载 **DuMate PC 客户端** 并安装；
2. 用**百度账号**登录（记住用的哪个账号，后面作品链接要挂在这个账号下）。

---

## 第 1 步 · 导入 5 个 Skill（10 分钟）

官方路径：**左上角「技能」→ 右上角「安装技能」→ 选择文件上传**（支持 `.zip` / `.md`，每次一个文件，≤30MB）。

按这个顺序逐个上传 `skills-zip/` 里的文件：

| 顺序 | 文件 | 技能名 | 作用 |
|---|---|---|---|
| 1 | `health-ripple.zip` | health-ripple | **核心**：健康事件涟漪推演 + 反事实护栏 + 五 Agent MDT |
| 2 | `medical-triage.zip` | medical-triage | 主动式分诊导诊（急诊指征主动判定 + 决策证据链） |
| 3 | `prescription-safety.zip` | prescription-safety | 处方安全**主动拦截**（过敏史/相互作用） |
| 4 | `medical-record-draft.zip` | medical-record-draft | 病历草稿生成 |
| 5 | `followup-plan.zip` | followup-plan | 随访计划与提醒 |

装完在 **「我的技能」→「自定义安装」** 里能看到 5 个技能包，逐个**开启**（右侧开关）。

> ⚠️ 导入外部 Skill 时平台会做安全沙箱审核（Skill Scanner）。**实测会弹出"风险等级：中"**——权限风险提示"可能执行本地命令"（误报，脚本为纯标准库、无 subprocess/os.system/eval），数据收集/外传/网络访问警告（真实但可控：只连本机 `SCB_GATEWAY_URL` 网关、只写技能自身目录的证据链与审计日志、PHI 落盘前已脱敏）。**点「我已知晓风险，开启使用」即可**；5 个技能的 SKILL.md 均含《数据流与权限说明》章节，可对照解释（答辩加分点：主动透明地披露数据流，配合项目自带的安全自审报告）。

## 第 2 步 · 关于"智能体/套件"（2026-09-23 实测修正）

**结论：DuMate 没有传统"智能体"对象，也不需要创建。** 它的能力模型是：

| 概念 | 说明 | 本作品怎么做 |
|---|---|---|
| **技能（Skill）** | 安装后全局可用，在符合触发条件的任务中自动调用，也可手动 `/技能名` | 第 1 步已装 5 个 → **即可直接用** |
| **套件（Suite）** | 多个技能打包成场景化能力，可"挂载到任务" | **可选**：点「+ 添加 → 创建套件」会跳转到对话页——这是它的设计（用一句话描述创建），不是失败。对提交没有硬性要求 |
| **人设/系统提示词** | ❌ 公开文档与客户端均无此设置项 | 输出纪律已写进 5 个技能的 SKILL.md（《呈现纪律》章节），模型调用技能时会读到 |

**官方提交要求对照**（见 `官方通知-iCAN-AI无代码智能体挑战赛.md` 第五章）：
- 「在 DuMate PC端完成作品创作」→ 安装并启用 5 个技能 ✅
- 「完成智能体对话后分享并保存链接」→ 跑通第 3 步的指令链，点分享 ✅（**不需要先创建智能体**）
- 「如有进行 skill 开发，可配套提供」→ 5 个技能的截图与 zip ✅

**若想让作品广场展示更完整（可选，10 分钟）**：在「+ 添加 → 创建套件」的对话页里直接发这句话，让搭子帮你建一个场景套件：

```
帮我创建一个套件，名称「健康事件涟漪守护智能体」，用于基层医疗诊后守护场景，把已安装的 health-ripple、medical-triage、prescription-safety、medical-record-draft、followup-plan 五个技能组合进去。
```

建好后在「专家套件」页能看到它，进详情页点「去使用」会自动挂载到新任务。**这一步不成功也完全不影响提交**。

**如果对话输出里出现模型自己的医学扩写**（如技能只返回"心内科"、模型又自行补充"建议挂内分泌科查血糖"），用一句话在对话里纠偏即可（无需任何配置）：

```
请严格按技能返回的字段原样呈现，包括 decisionId 与防篡改哈希；不要用你自己的医学知识补充技能未返回的建议。
```

> **环境变量（可选）**：客户端若在技能/任务设置里提供环境变量项，填 `SCB_GATEWAY_URL=http://localhost:18080`（本机 Docker 全栈网关）。系统用户级环境变量已由 `scripts/refresh_skill_tokens.py` 维护（含双角色令牌），一般无需手工填写。

> **实测结论（2026-09-23）**：DuMate PC 客户端的技能在**本机执行**——已用数据库记录验证：客户端发起的对话会在后端产生真实的 `triage_record` 行与 `ai_generation_log` 记录（患者1/心内科/置信度0.8），即技能确实连上了你本机的 `localhost:18080`，**不是降级模式**。
> 若换到不连本机后端的机器/云端沙箱：技能内置知识库降级模式会在输出里如实标注 degraded，功能照常（"AI 失败不中断流程"本身是加分点）。想现场展示"真连后端"，用本机终端直接跑 `dumate-skills/*/scripts/main.py`（评委指导书里的终端演示那条）。

## 第 3 步 · 对话测试（10 分钟，这 5 条跑通就说明接好了）

在新智能体对话框里依次发送：

1. `/medical-triage 我父亲65岁，最近总是口渴、喝水多、尿多，还觉得有点胸闷，应该挂哪个科？`
   → 应触发**分诊**：推荐心内科 + 置信度 + 决策证据卡片
2. `/medical-triage 为什么推荐心内科而不是内分泌科？给我看看决策证据`
   → 应展开**考虑因素/排除项/哈希**（高光帧：可追问的 XAI）
3. `/health-ripple 患者新诊断2型糖尿病，已开二甲双胍，推演健康事件涟漪`
   → 应输出**五维涟漪图谱** + 反事实护栏（FLAGGED 锁定条数）
4. `/prescription-safety 患者ID 1，开阿莫西林+布洛芬`
   → 应**主动拦截**（青霉素过敏，患者1）+ 给替代方案（全片最有冲击力的一步）
5. `/medical-triage 患者男，58岁，突发胸痛伴呼吸困难、大汗20分钟`
   → 应**主动判定急诊**、红色警示、不走普通挂号

对话里也可以用 `/技能名` 手动调用（如 `/health-ripple`）。**2026-09-23 提示**：若平台不自动触发（部分账号/版本不支持自动调用），把 `/技能名` 直接写在消息最前面即可，例如：

```
/medical-triage 我父亲65岁，最近总是口渴、喝水多、尿多，还觉得有点胸闷，应该挂哪个科？
/prescription-safety 患者ID 1，开阿莫西林+布洛芬
/followup-plan 患者ID 1，诊断2型糖尿病，开二甲双胍0.5g每日两次，生成随访计划
/medical-record-draft 挂号ID 6668，生成病历：患者诉多饮多尿1月伴胸闷，诊断2型糖尿病，开二甲双胍
```

判定技能是否真的在跑：输出含 `decisionId`/哈希/置信度/`PROACTIVE_xxx`/`FLAGGED` 等结构化字段 = 在跑；纯聊天大白话 = 没跑。

## 常见问题

| 现象 | 处理 |
|---|---|
| 技能导入被安全审核拦下 | 确认上传的是 `skills-zip/` 里打包好的文件（只读取参数、写自身目录）；重试一次或换 `.md` 方式上传 SKILL.md |
| 技能不自动触发 | 用 `/技能名` 手动调用；或在描述里带上触发词（如"分诊""涟漪推演""处方审核""随访"） |
| 输出里出现 degraded / 降级 | 正常现象：技能连不到后端网关，走内置知识库。照常讲解降级机制（加分项） |
| 想让它真连后端 | 本机跑 `docker compose -f deploy/docker-compose.yml up -d`，用终端直接执行 `python dumate-skills/health-ripple/scripts/main.py --action ripple --diagnosis "2型糖尿病" --patient-id 1`，环境变量 `SCB_GATEWAY_URL=http://localhost:18080` |
| 忘记报名要填什么 | 见 `00-提交清单与说明.md` 第四节「明早作战清单」 |
