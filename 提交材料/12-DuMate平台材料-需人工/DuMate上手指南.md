# DuMate 平台从零上手指南（本作品专用）

> 目标：把本作品的 5 个 Skill 装进 DuMate、建出智能体、跑通演示、拿到提交所需的链接与截图。
> 前置：技能包已打好在 `skills-zip/` 目录（5 个 zip，每个内含 `SKILL.md` + `scripts/main.py`，纯 Python 标准库、无第三方依赖）。

---

## 第 0 步 · 装客户端（5 分钟）

1. 打开官网 **https://www.dumate.cn/** 下载 **DuMate PC 客户端** 并安装；
2. 用**百度账号**登录（记住用的哪个账号，后面作品链接要挂在这个账号下）。

---

## 第 1 步 · 导入 5 个 Skill（10 分钟）

官方路径：**左上角「技能」→ 右上角「安装技能」→ 选择文件上传**（支持 `.zip` / `.md`，每次一个文件，≤30MB）。

按这个顺序逐个上传 `skills-zip/` 里的文件：

| 顺序 | 文件 | 技能名 | 作用 |
|---|---|---|---|
| 1 | `health-ripple.zip` | health-ripple | **核心**：健康事件涟漪推演 + 反事实护栏 + 五 Agent MDT |
| 2 | `medical-triage.zip` | medical-triage | 主动式分诊导诊（急诊指征主动判定 + 决策证据链） |
| 3 | `prescription-safety.zip` | prescription-safety | 处方安全**主动拦截**（过敏史/相互作用） |
| 4 | `medical-record-draft.zip` | medical-record-draft | 病历草稿生成 |
| 5 | `followup-plan.zip` | followup-plan | 随访计划与提醒 |

装完在 **「我的技能」→「自定义安装」** 里能看到 5 个技能包，逐个**开启**（右侧开关）。

> ⚠️ 导入外部 Skill 时平台会自动做安全沙箱审核；本作品技能只读参数、只写自己目录下的审计/证据文件，正常会通过。

---

## 第 2 步 · 建智能体并绑定技能（10 分钟）

1. 新建一个**智能体**，名称建议：**健康事件涟漪守护智能体**（对外材料统一用这个，不要写"智慧云脑"——本次品牌已统一为「涟漪守护」）；
2. 简介一句话（可直接粘贴）：
   > 新诊断、新处方发生时，主动推演其在患者生活中的多维连锁影响（用药冲突/复查窗口/并发症信号/家属注意/触达时机），并给出可审计、可拦截、可终审的守护计划。
3. **绑定上一步的 5 个技能**；
4. 系统提示词建议（粘贴到智能体人设/指令里）：

```
你是「健康事件涟漪守护智能体」，服务基层医生与慢病患者。规则：
1) 用户描述症状 → 调用 medical-triage 给出科室建议与置信度，并保留决策证据链（可被追问"为什么"）；
2) 出现急诊指征（如突发胸痛伴大汗）→ 不等用户选号，主动红色警示并引导急诊；
3) 新诊断/新处方 → 调用 health-ripple 推演五维涟漪影响，并标注每条触达的循证依据（Timing Card）；
4) 开药前必须调用 prescription-safety 做过敏与相互作用审查，高危直接拦截并给替代建议；
5) 疑难病例调用 health-ripple 的 MDT 动作做五 Agent 会诊；
6) 任何情况下：不开方、不下诊断、不改治疗方案，终审权永远在医生。
```

5. **环境变量（可选）**：若智能体/技能配置里有环境变量项，填：
   - `SCB_GATEWAY_URL=http://localhost:18080`（本机 Docker 全栈网关）
   - `SCB_API_TOKEN=<医生登录返回的 JWT>`（在线模式需要；医生账号 `doctor1 / 123456`）

> **重要认知**：如果技能运行在平台云端，是连不到你本机 `localhost:18080` 的——**完全不影响演示**。5 个技能都内置知识库降级模式，会在输出里如实标注 degraded，功能照常；这本身就是作品的加分点（"AI 失败不中断流程"）。想现场展示"真连后端"，就用本机的 `dumate-skills/*/scripts/main.py` 直接在终端跑（评委指导书里的终端演示那条）。

## 第 3 步 · 对话测试（10 分钟，这 5 条跑通就说明接好了）

在新智能体对话框里依次发送：

1. `我父亲65岁，最近总是口渴、喝水多、尿多，还觉得有点胸闷，应该挂哪个科？`
   → 应触发**分诊**：推荐心内科 + 置信度 + 决策证据卡片
2. `为什么推荐心内科而不是内分泌科？给我看看决策证据`
   → 应展开**考虑因素/排除项/哈希**（高光帧：可追问的 XAI）
3. `患者新诊断2型糖尿病，已开二甲双胍，推演健康事件涟漪`
   → 应输出**五维涟漪图谱** + 反事实护栏（FLAGGED 锁定条数）
4. `给患者开阿莫西林和布洛芬`
   → 应**主动拦截**（青霉素过敏，患者1）+ 给替代方案（全片最有冲击力的一步）
5. `患者男，58岁，突发胸痛伴呼吸困难、大汗20分钟`
   → 应**主动判定急诊**、红色警示、不走普通挂号

对话里也可以用 `/技能名` 手动调用（如 `/health-ripple`）。

## 常见问题

| 现象 | 处理 |
|---|---|
| 技能导入被安全审核拦下 | 确认上传的是 `skills-zip/` 里打包好的文件（只读取参数、写自身目录）；重试一次或换 `.md` 方式上传 SKILL.md |
| 技能不自动触发 | 用 `/技能名` 手动调用；或在描述里带上触发词（如"分诊""涟漪推演""处方审核""随访"） |
| 输出里出现 degraded / 降级 | 正常现象：技能连不到后端网关，走内置知识库。照常讲解降级机制（加分项） |
| 想让它真连后端 | 本机跑 `docker compose -f deploy/docker-compose.yml up -d`，用终端直接执行 `python dumate-skills/health-ripple/scripts/main.py --action ripple --diagnosis "2型糖尿病" --patient-id 1`，环境变量 `SCB_GATEWAY_URL=http://localhost:18080` |
| 忘记报名要填什么 | 见 `00-提交清单与说明.md` 第四节「明早作战清单」 |
