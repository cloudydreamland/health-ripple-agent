# RII 开放规范 v1.0（Ripple Intensity Index Specification）

> 本规范定义**健康事件涟漪强度指数（RII）**的计算口径、等级语义与可复算性要求，
> 使任何医疗信息系统（HIS/互联网医院/可穿戴/慢病管理平台）可以用同一套公式
> 计算、比对、审计"一个健康事件在患者生活中激起的连锁影响强度"。
>
> 参考实现（Java，含全部边界与单测）：`backend/ripple-service/.../RippleIntensityModel.java`
> 量化验证：`evaluation/ripplebench/`（60 开发病例 + 10 盲测病例）

---

## 1. 模型对象

- **健康事件**：一次新诊断 / 新处方 / 异常指标（输入：诊断、用药、既往史）。
- **涟漪节点**：该事件在患者生活中激起的一条具体连锁影响，归属于五个环层：

| 环 r | 环名 | 典型内容 |
|---|---|---|
| 1 | 用药安全圈 | 药物-生活冲突（饮酒、造影剂、饮食…） |
| 2 | 疾病进展圈 | 并发症早期信号 |
| 3 | 复查窗口圈 | 复查/化验窗口 |
| 4 | 触达时机圈 | 时间学触达（窗口/节律/周期/季节） |
| 5 | 家庭影响圈 | 家属注意事项 |

## 2. 节点强度

```
nodeIntensity = 100 × S × U × A × e^(−λ·(r−1))
```

| 量 | 含义 | 取值域 | 评定来源 |
|---|---|---|---|
| S | 严重度 severity | 0–0.95 | 知识条目（指南/研究引用） |
| U | 紧迫度 urgency | 0–1.0 | 知识条目 |
| A | 可干预度 actionability | 0–0.95 | 知识条目 |
| λ | 空间衰减系数 | 0.22 | 见 §5 推导 |
| r | 环层 | 1–5 | §1 |

**每一次计算必须输出 S/U/A/衰减四项分项**（scoreBreakdown），供医生逐项复算——
只给结果不给依据的强度分不符合本规范。

## 3. 事件级指数

```
RII = mean(top5(nodeIntensity))       （节点不足5个按实际数量取均值）
理论量程 0–90.25（上限 = 100 × 0.95 × 1.0 × 0.95）
```

## 4. 等级与半径

- **等级**：RED（≥45，红色·高强度涟漪）/ ORANGE（≥25，橙色·中度涟漪）/ YELLOW（<25，黄色·观察涟漪）。
- **有效扩散半径 radius**：存在强度 ≥15 的节点的最大环层 r。
- **Top 风险节点**：按强度降序输出（医生视线第一落点）。

## 5. λ=0.22 与阈值 45/25 的推导依据（不可篡改的设计记录）

- e^(−0.22) ≈ 0.802，即影响每外移一环衰减约 **19.8%**——五环后剩余 ≈ 33%，
  对应"家庭注意事项仍值得认真对待、但弱于用药安全"的临床直觉。
- 环1高危节点（S=0.95, U=0.9, A=0.9）强度 ≈ 77–81；环1中危节点 ≈ 35。
  因此 **Top5 均值 ≥45 当且仅当"近环高风险"在节点构成中占主导**——这就是 RED
  阈值的语义：不是"有事就算红"，而是"风险主体就在患者自己身上"。
- 量程上界 90.25 < 100：刻意留出与绝对压力校准的空间（红≠系统崩溃）。

## 6. 时间学叠加与预报（扩展维度）

72 小时预报 = 各活跃触达的节点强度在时间轴上的**确定性叠加**（无随机数）：

| 类型 | 激活形状 | 语义 |
|---|---|---|
| WINDOW | 高斯尖峰 σ=1.5h | 黄金窗口错过即衰减 |
| RHYTHM | 高斯尖峰 σ=1.2h × 未来4日 | 每日节律时段 |
| PERIODIC | 高斯宽峰 σ=6h | 复查行动窗口 |
| SEASONAL | 目标月低幅基线 ×0.25 | 环境因素，不硬造峰值 |

消解联动：RESOLVED/ESCALATED/VETOED 剔除；UNRESOLVED ×1.5 加压。
依从性沙盘：非季节驱动贡献 ×(1−守护执行度)，同一引擎重算。

## 7. 可复算性要求（合规底线）

1. 任何 RII/预报输出必须附带分项依据（S/U/A/衰减、逐桶驱动事件）。
2. 相同输入必须得到相同输出（禁止隐式随机）；时区/墙钟差异必须可注解。
3. 输出的每一次**人工修订**（医生审定）必须作为独立决策记录进入审计链，
   记录"谁、何时、以什么理由"改变系统行为（见 GUARD_PLAN_REVIEW 决策类型）。
4. 知识条目更新后，历史证据不得回写重算（append-only）。

## 8. 评测协议

- 开发集：链路对齐（允许源自内置知识库）。
- **盲测集**：金标准依据外部指南独立制定，开发期不可见——报告泛化能力。
- 必报指标：分诊/涟漪覆盖 top-1、护栏灵敏度与特异度、消解闭环数学、诚实降级率。
